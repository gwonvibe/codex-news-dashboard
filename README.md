# 인공지능 뉴스 키워드 대시보드

Codex 바이브코딩 과정 **실습③ 완성본**입니다. Google 뉴스 공개 RSS에서 모은 기사 제목으로 키워드 순위(TOP 8)를 막대그래프로 보여주고, 최근 뉴스 20건을 링크와 함께 나열합니다.

코드를 손으로 쓰지 않았습니다. `PROMPT.txt` 안의 문장을 Codex에 그대로 넣어서 나온 결과입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 대시보드 본체. 데이터가 파일 안에 들어 있어 그냥 열면 됩니다 |
| `news.json` | 수집한 원본 기사 데이터 |
| `PROMPT.txt` | 이걸 만들 때 Codex에 넣은 문장 |

## 직접 만들어 보려면

바탕화면에 빈 폴더를 하나 만들고 Codex에서 그 폴더를 연 다음, `PROMPT.txt` 내용을 붙여넣으면 됩니다. 데이터는 실행한 시점의 뉴스로 새로 모이니 결과 화면은 이 페이지와 다릅니다.
